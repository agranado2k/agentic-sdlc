# agentic-sdlc

A language-agnostic, agent-first SDLC framework — extracted from a production project where it was built, reviewed, and exercised by the very chain it defines.

**Status:** scaffolding. PRD in issue #1; built ticket-by-ticket via its own `/to-tickets` → `/implement` chain.

Spec → tracer-bullet tickets → test-first implementation → two-axis review (standards to agents, behavior changes to humans) → human merge gate. Constitution-layered agent instructions, CI-verified process docs, guards that block what prose used to merely request.
