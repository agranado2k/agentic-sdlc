## Problem

Every piece of work here is sized to one of four capability tiers (planner, implementer, mechanical, reviewer), and a policy file maps each tier, and some task domains, to a model. That mapping was set one decision at a time (ADR-0018, ADR-0020, ADR-0027) as models and usage limits changed, never from a single view of what each model is for. The question: which model should run each tier and domain, by what criteria (quality on that kind of work, cost, speed, usage window, a reviewer from a different family than the author), and when should the mapping be revisited?
