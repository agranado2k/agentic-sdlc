## Erratum — the deep read (2026-11-27)

The table above is kept as the operator gave it. Read through restricted readers on 2026-11-27,
it differs from the pages in these places; cite the pages, not the table.

- **&Truth:** the site states a mission only. It does not mention leaving stealth, a release
  date, public libraries, or plans to open-source Lean specifications; its one Lean FRO mention
  is an advisor's affiliation, not a collaboration.
- **Harmonic:** the IMO2025 repository matches. The site shows no public source for Aristotle,
  but never calls it proprietary, so that word is unverified.
- **Theorem:** `oss-verify` is enrollment and build tooling, not the verification
  infrastructure; `oss-verify-proofs` has 695 of 20,659 statements proved; `static-asan` is now
  `asan-static` (the old name redirects); `xv6iris` returned 404, so whether it is Lean or
  Rocq/Iris is unknown.
- **Axiom:** the organization has 74 repositories (matches "70+"). AXLE is "Python client and
  CLI for the AXLE Lean verification API", a client for a hosted service; `axplorer` is a
  neural-network-plus-search pipeline for extremal combinatorial objects, not a proof explorer.
  Stacks and CFSG match.
